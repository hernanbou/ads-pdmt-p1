## Como executar

1. Clone o repositório e instale as dependências:

   ```bash
   npm install
   ```

2. Preencha as chaves no arquivo `src/utils/chaves.js`:

   * **Geoapify:** obtenha uma chave gratuita em https://www.geoapify.com/
   * **PrimeUI:** solicite a licença Community em https://primeui.store/primeui

3. Inicie a aplicação:

   ```bash
   npm run dev
   ```

4. Abra o endereço informado no terminal. O navegador solicitará permissão para acessar sua localização.
